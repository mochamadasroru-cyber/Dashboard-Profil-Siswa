# Dashboard-Profil-Siswa

Aplikasi Dashboard Profil Siswa Al Fakhir.

## Fitur
- Pengelolaan data siswa, foto, paraf, dan catatan nilai/kegiatan.
- Desain cetak profil siswa dalam format PDF A4.
- Dukungan mode pratinjau interaktif dan editor template kustom.
- CSS eksternal terpisah (`style.css`).

## Menjalankan Proyek
```bash
npm install
npm run dev
```
Buka browser pada `http://localhost:5173/`.
